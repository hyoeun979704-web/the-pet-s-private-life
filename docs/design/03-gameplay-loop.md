# 03. 핵심 플레이 루프

> **읽는 시간**: 5~7분
> **목적**: 유저가 매일 무엇을 하는지, 어떤 자원이 어디에 쓰이는지

---

## 🔄 한 세션 (8~10분) 흐름

```
[1] 진입 — 메인 화면(거실) 등장
       ↓ 주인님이 idle 상태로 거실에서 어슬렁
       ↓ 어제와 달라진 점 발견 (새 가구·캐릭터)
[2] 자원 확인 (상단 HUD) — 간식·별먼지·마법돌
       ↓
[3] 미니게임 1~2회 (5분)
       ↓ 블록 퍼즐 / 머지 / 퀴즈 중 택 1~2
       ↓ 자원 획득
[4] 가챠 또는 가구 구매 (선택)
       ↓ 새 캐릭터 영입 또는 거실 꾸미기
[5] 거실 변화 감상 → 종료
       ↓ "내일 또 봐야지"
```

---

## 📅 일/주/월 단위 루프

### 매일 (Daily)
- **출석 체크 보상** (`login_bonus`) — 7일 누적, 7일째 마법돌
- **퀴즈 1세션** (하루 1회 무료, 광고 보면 추가)
- **블록 퍼즐 / 머지** (피로도 한도 내 무제한)
- **데일리 미션 3개** (간단 — "퀴즈 1번 풀기", "가구 1개 배치하기")

### 매주 (Weekly)
- **주간 미션** (조금 더 어려움 — "캐릭터 3종 영입")
- **주간 가챠 할인 또는 보너스 회차** (선택, 후속 PART)

### 매월 (Monthly / 시즌)
- **시즌 가구 세트** 교체 (계절감 — 봄꽃 / 여름 해변 / 가을 단풍 / 겨울 크리스마스)
- **시즌 한정 캐릭터** (e.g. 산타 모자 쓴 시바)

---

## 💎 자원 시스템 — 5종

각 자원이 무엇을 위해 존재하는지가 명확해야 함. UI 아이콘에도 영향.

| 자원 | 아이콘 모티프 | 획득 | 사용처 |
|---|---|---|---|
| 🍪 **간식 (Snack)** | 동물 발 모양 쿠키, 갈색 | 블록 퍼즐, 데일리 미션 | 가구 구매, 캐릭터 피로도 회복 |
| ✨ **별먼지 (StarDust)** | 작은 별 + 반짝임, 노랑 | 머지 게임 | 가구 강화, 인테리어 업그레이드 |
| 💎 **마법돌 (MagicStone)** | 분홍 다이아몬드, 핑크 | 출석, 레벨업 | 가챠 1회 = 마법돌 1개 |
| 💠 **마법돌 조각 (Shard)** | 마법돌 깨진 조각 | 퀴즈, 가챠 중복 | 10조각 = 마법돌 1개 |
| 🎫 **가챠 티켓** | 분홍 티켓 모양 | 이벤트, 레벨업 | 가챠 1회 무료 |

> 추가로 거실 자체의 **"아늑함 점수 (Coziness)"** — 가구 배치로 올라가는 메트릭. 자원이라기보다는 도전 점수.

### 자원 획득 일일 한도 (참고)
- 간식: 200/일
- 별먼지: 50/일
- 퀴즈 세션: 1/일 (광고 시청 시 추가)
- → 한도 도달 시 잔여 시간 표시 ("00:00 KST에 리셋")

---

## 🎮 3가지 미니게임 (자원 사용처)

### 🧩 블록 퍼즐 (간식 획득)
- 우드락 트레이에 블록을 끼워 라인 완성
- 라인 클리어 시 간식이 우수수 떨어지는 연출
- 콤보 시 추가 보상
- → **05-spaces / 06-minigames** 에서 비주얼 디테일

### ✨ 머지 게임 (별먼지 획득)
- 같은 레벨의 별먼지를 합쳐 더 큰 별로
- Lv.1 → Lv.2 → ... → Lv.10 (레벨 7+ 부터 화려한 연출)
- → 합치는 순간 **별가루 폭죽** 연출

### ❓ 퀴즈 (마법돌 조각 획득)
- 반려동물 OX 또는 4지선다 퀴즈 (300문항 풀)
- 의료·과학 카테고리는 출처 명시 (한국 법규)
- 정답 시 카드 뒤집기 + 정답 공개 연출

---

## 🎰 가챠 시스템

### 코어 규칙
- 1회 = 마법돌 1개 또는 가챠 티켓 1개
- 17종 캐릭터 풀 (등급별 확률)
- **천장**: 20회 연속 일반 → 다음 회차는 희귀+ 확정
- 중복 시 자동으로 **마법돌 조각** 으로 변환

### 등급별 확률 (확정 — 법규 공시 의무)
| 등급 | 확률 |
|---|---|
| 일반 (Normal) | 70.00% |
| 희귀 (Rare) | 25.00% |
| 전설 (Legendary) | 5.00% |

### 가챠 비주얼
- **마법 캡슐** 연출 (도박장 X, 마법 모티프 O)
- 캡슐이 굴러오는 → 빛이 새어나옴 → 등급별 다른 빛 색
  - 일반: 흰빛
  - 희귀: 파랑빛
  - 전설: 무지개 + 별가루

---

## 🛋️ 가구·인테리어 시스템

### 가구 카테고리 (3종)
- **바닥 (Floor)**: 러그, 매트, 방석 → 50%
- **벽 (Wall)**: 액자, 시계, 식물 행잉 → 30%
- **소품 (Decor)**: 화분, 책, 컵, 인형 → 20%

### 두 개의 방
- **거실 (room_living)** — 메인, 처음부터 활성
- **침실 (room_bedroom)** — 레벨 5에 활성
- (Phase 2: 부엌 `room_kitchen` — 추후)

### 가구 구매 → 배치
1. 가구 상점에서 간식·별먼지로 구매
2. 보관함에 들어옴
3. 방 편집 모드에서 끌어다 배치 (스냅 그리드)
4. 회전 가능 (4방향)
5. 모든 배치는 즉시 거실 화면에 반영

### 아늑함 점수
- 가구 종류 다양성 + 배치 밀도로 계산
- 점수 ↑ → 주인님이 거실에 더 오래 머무는 idle 패턴
- 마일스톤 (Cozy 100 / 500 / 1000)에 보상

---

## 📈 레벨 & 진행

### 유저 레벨 (1 ~ 50)
- EXP 누적: 미니게임 클리어, 데일리 미션 완료, 광고 시청
- 레벨업 시 보상 (간식·별먼지·마법돌·티켓)
- 레벨 5: 침실 해금
- 레벨 10: 머지 게임 Lv.7+ 해금
- 레벨 20: 시즌 콘텐츠 해금

### 캐릭터 레벨 (각 캐릭터 1 ~ 10)
- 가구 배치 + 미니게임 시 함께 있는 캐릭터에 EXP
- 레벨업 시 피로도 최대치 ↑ + 그루브 idle 모션 추가

---

## ⏰ 피로도 시스템 (긴 플레이 방지)

각 캐릭터는 **피로도 (10~15)** 보유.
- 미니게임 진입 시 캐릭터 1마리당 1~4 피로도 소모
- 30분에 1씩 자동 회복
- 광고 시청 시 +3 즉시 회복 (1일 3회 제한)
- → **유저가 너무 오래 게임 못하게** 막는 의도된 게이트
