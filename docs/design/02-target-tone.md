# 02. 타겟 & 톤·매너

> **읽는 시간**: 5분
> **목적**: 누구를 위한 게임인지 + 어떤 분위기로 만들어야 하는지

---

## 👤 타겟 페르소나

### 메인 페르소나: 30살 직장인 여성 "수진"
- 평일 오전 9~6시 사무직, 퇴근 후 1시간 자유 시간
- 실제 반려동물(고양이·강아지) 키우거나 키우고 싶어 함
- 인스타그램에서 동물 영상 매일 봄
- 게임은 **출퇴근 지하철 5분 + 자기 전 10분**
- 무거운 RPG·전략 X, 가벼운 캐주얼 O
- 결제 의향: 월 1~3만원 (귀여운 캐릭터·꾸미기에 한정)

### 서브 페르소나: 24살 대학생 "민지"
- 자취, 반려동물은 못 키우지만 동물 영상 매일 봄
- 인스타·유튜브 무드보드 따라하기 좋아함
- 친구에게 추천할 만한 **인스타에 올릴 만한 비주얼** 중요
- 결제 의향: 한 달에 한 번, 가챠 5천 원

### 서브 페르소나: 38살 워킹맘 "지영"
- 아이가 자고 난 후 30분이 유일한 자유 시간
- 시간 압박 게임 절대 X (현실에서 충분히 시달림)
- 짧고 따뜻한 보상 + 사소한 성취감 원함

### 공통점 (가장 중요)
- **여성 (90%+)**
- **20~40대**
- **반려동물 호감 또는 보유**
- **"힐링" 카테고리 게임 검색 경험**

## 🎨 비주얼 톤 — 무드보드 키워드

### 톤 매트릭스 (좌→우 / 위→아래)

```
                  차가움
                    │
                    │
      모던 미니멀 ── │ ── 시크 / 유럽풍
                    │
   따뜻함 ─────────┼───────── 냉정함
                    │
      코지 카페 ── │ ── 키덕스 / 캐릭터스튜디오
            (★)    │
                    │
                  유아틱
```

★ 우리는 **"코지 카페" 사분면** — 따뜻함 + 어른스러움.

### 무드보드 키워드 30선

**공간**
- 늦은 오후 햇살이 들어오는 카페
- 작은 화분이 놓인 창가
- 부드러운 면 소재 쿠션
- 베이지 / 크림 / 분홍 / 옅은 민트
- 작은 식물 (몬스테라, 율마, 다육이)
- 따뜻한 노란 조명 (백열등 톤)
- 패브릭 러그 / 우드 바닥
- 해 질 녘 창문 너머 풍경

**감정**
- 안전함 / 보호받는 느낌
- 작은 행복 / 소소한 발견
- 아늑함 / 포근함
- 살짝 짠한 / 위트 있는

**브랜드 레퍼런스 (시각적 영감)**
- Studio Ghibli 인테리어 스틸컷
- 산리오 (단, 너무 어리지 않게)
- 카카오프렌즈 / 라인프렌즈 (단, 더 따뜻하게)
- 일본 잡화 브랜드 (Niko and..., Afternoon Tea)
- 핀터레스트 "cozy interior aesthetic"

**참고 게임 (비주얼 톤)**
- Animal Crossing (밝고 따뜻한 색)
- Cozy Grove (수채화 톤)
- A Little to the Left (오브젝트 클로즈업, 미니멀)
- Unpacking (인테리어 픽셀 아트, 우리는 비픽셀)

## ✍️ 어조 (텍스트 톤)

### 게임 내 안내문 / 시스템 메시지
- ~예요, ~네요 (친근, 부드러움)
- 명령조 X — "탭하세요" 보다 "탭해 보세요"
- 부정문 최소화 — "실패" → "조금만 더!"

### 캐릭터 텍스트 (도감)
- ~다, ~함 (도감 카드 톤)
- 위트 한 스푼 ("도도하지만 외로움 잘 탐")

### 마케팅 카피
- 따뜻함 + 호기심 자극
- "발견하다", "함께", "조용히" 같은 단어

### 절대 쓰지 않는 표현
- "지금 결제!" (강요)
- "한정 특가!" (조급함)
- "랭킹 1위!" (경쟁)
- "최강!" (자극)

## 🚫 금기 (Visual Don'ts)

다음 요소는 절대 등장하지 않습니다:

| 항목 | 이유 |
|---|---|
| 순흑·순백·네온 컬러 | 톤 깨짐 |
| 사람 캐릭터 (얼굴) | 동물이 주인공. 사람은 손/그림자만 |
| 무기·전투·피 | 비폭력 |
| 술·담배·약물 | 14+ 등급 |
| 도박장·카지노 비주얼 | 가챠 톤 분리 (가챠는 마법 캡슐 / 별먼지 모티프) |
| 슬픔 (눈물·아픈 표정) | 힐링 게임 |

## 💡 작업할 때 의심 들면

> **"이게 늦은 오후, 따뜻한 거실에서 차 한 잔 마시며 보는 풍경에 어울리나?"**

이 한 문장이 가장 강한 필터. 어울리지 않으면 톤이 어긋난 것.
