# 07. UI/UX 톤

> **읽는 시간**: 5분
> **목적**: 버튼·창·아이콘이 어떤 모양·색이어야 하는지

---

## 🎨 디자인 토큰 (확정)

코드에 이미 적용된 값. **모든 UI 자산은 이 값에 맞춰 작업**.

### 색

```
Primary       #FFC8DD   (메인 분홍)
Primary↓      #E8A4BF   (강조 분홍 — hover/pressed)
Secondary     #FAEDCB   (베이지 크림)
Accent        #A0C4FF   (라벤더 블루)
Success       #B9FBC0   (민트 — 완료/정답)
Danger        #FFADAD   (살구 — 경고/실패)
Text Primary  #3A2E2A   (다크 브라운 — 본문)
Text Secondary #7A6A66  (회갈색 — 보조)
BG Main       #FFF7F2   (따뜻한 화이트)
BG Alt        #F3E8E2   (살짝 어두운 베이지)
```

### 모서리 (Radius)
- Small: 8px (작은 버튼·태그)
- Medium: 12px (카드)
- Large: 20px (모달·큰 패널)
- Pill: 999px (둥근 버튼·인디케이터)

### 간격 (Spacing)
- xs: 4 / sm: 8 / md: 16 / lg: 24 / xl: 32

### 폰트
- 기본: **Pretendard** (한글 우선) → fallback **Noto Sans KR**
- 사이즈: sm(14) / md(18) / lg(24) / xl(32)
- 굵기: 일반 본문 400, 강조 600, 헤더 700

### 그림자
- Soft: `0 4px 12px rgba(58, 46, 42, 0.08)` (작은 카드)
- Medium: `0 8px 20px rgba(58, 46, 42, 0.12)` (모달)

## 🔘 버튼

### 1차 버튼 (메인 행동)
```
┌─────────────────┐
│   [뽑기]         │   ← #FFC8DD 배경, 흰 텍스트
└─────────────────┘
```
- 배경: Primary #FFC8DD
- 텍스트: 화이트 (또는 Text Primary 어두운)
- 모서리: Medium (12px)
- 그림자: Soft
- 호버/터치: Primary↓ #E8A4BF 로 살짝 진하게

### 2차 버튼 (보조)
- 배경: 흰
- 테두리: Primary 2px
- 텍스트: Primary

### 3차 버튼 (텍스트만)
- 배경 없음
- 텍스트: Primary
- 밑줄 없음, 호버 시 옅은 분홍 박스

### 위험 버튼 (삭제·로그아웃)
- 배경: Danger #FFADAD
- 텍스트: 어두운 텍스트

### 비활성 버튼
- 배경: BG Alt #F3E8E2
- 텍스트: Text Secondary
- 살짝 흐릿 (opacity 0.7)

### 버튼 사이즈
- 모바일 최소 탭 영역: **44dp** (Android 가이드)
- 큰 메인 버튼: 높이 56px, 폭 220px 이상

## 🖼️ 카드 / 패널

### 일반 카드
- 배경: 흰
- 테두리: 없음 또는 BG Alt 1px
- 모서리: Medium (12px)
- 그림자: Soft
- 패딩: 16px

### 캐릭터 카드 (도감)
- 정사각 또는 3:4 비율
- 상단: 캐릭터 일러스트
- 하단: 이름·등급 배지
- 등급 배지:
  - 일반: 회색 / 베이지
  - 희귀: 파랑 #A0C4FF
  - 전설: 골드 그라데이션

### 모달
- 배경: 흰
- 모서리: Large (20px)
- 그림자: Medium
- 백드롭: 검정 40% + 블러 8px

## 📊 상단 HUD (Heads-Up Display)

거실 / 미니게임 상단에 항상 떠 있는 자원 표시.

```
┌──────────────────────────────────────────┐
│ 🍪 1,234   ✨ 56   💎 12   [Lv.5] [⚙]   │
└──────────────────────────────────────────┘
```

### 디자인
- 배경: 흰 + 그림자 (반투명 X)
- 자원 아이콘 + 숫자 한 묶음
- 아이콘 크기: 24px
- 숫자 폰트: 굵기 600
- 우측 끝: 레벨 + 설정 톱니

### 자원 부족 강조
- 자원이 0 또는 부족할 때: 살짝 빨간 강조 (살구 #FFADAD 펄스)

## 🎯 아이콘 스타일

### 공통
- **선이 있는 아이콘** (라인 + 채움 혼합)
- 라인 색: 텍스트 컬러와 일치 (#3A2E2A)
- 채움: 캐릭터 톤과 비슷한 파스텔
- 사이즈: 16 / 24 / 32 / 48 / 64

### 카테고리별

**자원 아이콘** (24~32px)
- 🍪 간식: 발모양 쿠키, 갈색
- ✨ 별먼지: 작은 별 + 반짝, 노랑
- 💎 마법돌: 분홍 다이아, 핑크
- 💠 마법돌 조각: 깨진 다이아, 옅은 분홍
- 🎫 가챠 티켓: 분홍 티켓

**시스템 아이콘** (24px)
- 설정 ⚙
- 닫기 ✕ (살짝 둥근 X)
- 뒤로 ←
- 도움말 ?
- 알림 🔔
- 정보 ℹ

**메뉴 아이콘** (48px)
- 가구 상점 🛋
- 가챠 🎰 (캡슐 자판기 미니)
- 도감 📖
- 미니게임 🎮 (3종 분리)

> 정확한 아이콘 목록 → [`docs/assets/04-ui-icons.md`](../assets/04-ui-icons.md)

## 🪟 화면 전환 / 애니메이션

### 페이지 전환
- 거실 ↔ 미니게임: **슬라이드 + 살짝 페이드** (0.4초)
- 모달 띄우기: **아래에서 위로 슬라이드** + 페이드 (0.3초)
- 모달 닫기: 위에서 아래로

### 마이크로 인터랙션
- 버튼 탭: **0.95 배 살짝 줄어들었다가 복귀** (스프링)
- 카드 뒤집기: **Y축 회전** (0.5초)
- 보상 획득: **0 → 1.2 → 1.0 배** 바운스 (스프링)

### 로딩
- 스피너 X (회전 원반은 차가움)
- **점 3개 통통 튀는** 애니메이션 + 캐릭터 발자국

## 🔤 텍스트 가이드

### 위계
| 종류 | 사이즈 | 굵기 | 색 |
|---|---|---|---|
| 페이지 제목 | 32 | 700 | Text Primary |
| 섹션 제목 | 24 | 700 | Text Primary |
| 본문 | 18 | 400 | Text Primary |
| 보조 텍스트 | 14 | 400 | Text Secondary |
| 캡션 | 12 | 400 | Text Secondary |

### 줄 간격
- 본문: 1.6
- 제목: 1.4

### 한국어 줄바꿈
- 명사구 단위로 끊기 ("주인님이 / 자리를 비운 / 사이...")
- 어미만 다음 줄로 가는 것 방지 (`word-break: keep-all`)

## 🔆 접근성

코드에 이미 적용된 값:

- **Large Font** 토글: 1.2배 확대 옵션
- **Reduce Motion** 토글: 애니메이션 최소화
- **Min Tap Target**: 44dp (Android 표준)
- **Contrast**: 본문 텍스트 4.5:1 이상

→ 일러스트도 너무 작은 디테일은 피하기 (시력 약한 사용자 배려)

---

## 📱 화면 비율 / 안전 영역

### 화면 가로 (Landscape)
- 베이스: 1920×1080
- 21:9 노치 폰 대응: 좌우 80px 안전 마진

### 화면 세로 (Portrait — 사용 X)
- 우리 게임은 **가로 전용**
- Capacitor 설정으로 강제 landscape 고정

---

## 🚫 UI Don'ts

- ❌ 너무 많은 색 (한 화면에 5색 이상)
- ❌ 검정 배경 + 흰 텍스트
- ❌ 그라데이션 남발 (포인트 1~2곳만)
- ❌ 작은 텍스트 (14px 미만)
- ❌ 차가운 회색 (#888 등)
- ❌ 강한 빨강 / 강한 파랑 (살구 / 라벤더로)

## 🎨 작업 우선순위

### Phase 1 (MVP)
- [ ] 1차 버튼 1종 (3 상태: 기본/호버/비활성)
- [ ] 자원 아이콘 5종 (HUD용)
- [ ] 닫기 / 설정 / 뒤로 아이콘 3종
- [ ] 캐릭터 카드 1종 (도감 베이스)

### Phase 2 (정식)
- [ ] 메뉴 아이콘 6종 (가구·가챠·도감·미니게임 3)
- [ ] 모달 베이스 1종
- [ ] 등급 배지 3종

### Phase 3 (폴리싱)
- [ ] 알림 / 정보 / 도움말 추가 아이콘
- [ ] 빈 상태 일러스트 (도감 비었을 때 등)
