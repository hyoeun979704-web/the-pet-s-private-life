# 06. 미니게임 비주얼 디렉션

> **읽는 시간**: 7분
> **목적**: 3가지 미니게임이 어떤 모습이어야 하는지 (자산 + 연출)

---

## 🎮 공통 원칙

### 1. 미니게임 진입은 "방으로 들어가는 경험"
- 거실 → 미니게임 = 페이지 전환이 아니라 **줌인 / 슬라이드**
- 거실이 살짝 보이는 상태에서 게임이 띄워짐
- 종료 시 자연스럽게 거실로 페이드아웃

### 2. 보드는 따뜻한 재질
- 차가운 검정·강철 X
- **나무 / 패브릭 / 종이** 재질감
- 살짝 입체감 (얕은 그림자)

### 3. 보상 연출은 풍부하게
- 라인 클리어, 머지 성공, 정답 → **별가루 + 아이콘 비처럼 떨어짐**
- 짧지만 임팩트 있게 (1초 이내)

---

## 🧩 1) 블록 퍼즐 (BlockPuzzle)

### 컨셉
> "주인님 간식 그릇을 채우는 따뜻한 퍼즐"

### 화면 구성
```
┌────────────────────────────────────┐
│ [상단 HUD]  스코어 / 콤보         │
├────────────────────────────────────┤
│                                    │
│      ┌──────────────────┐          │
│      │                  │          │
│      │   [9×9 보드]     │          │
│      │                  │          │
│      │                  │          │
│      └──────────────────┘          │
│                                    │
│   [블록1] [블록2] [블록3]          │  ← 트레이
└────────────────────────────────────┘
```

### 비주얼 요소

**보드**
- 9×9 격자 (옅은 베이지 + 분홍 라인)
- 셀: 64×64 px
- 빈 셀: 살짝 들어간 음각 느낌

**블록 (5~7가지 색)**
- 분홍 #FFC8DD
- 민트 #B9FBC0
- 노랑 #FAEDCB
- 살구 #FFADAD
- 연파랑 #A0C4FF
- 라벤더 #C8B6FF (선택)
- 베이지 #FAEDCB

> 블록 끝부분 살짝 둥글게. 도형은 테트리스 스타일 7~10종.

**트레이 (하단)**
- 나무 톤 받침대
- 3개의 블록이 대기

**라인 클리어 연출**
- 클리어된 라인이 **빛나며 사라짐**
- 사라진 자리에서 **간식 아이콘**(🍪 발모양 쿠키)이 비처럼 떨어짐
- 콤보 시 화면 가장자리에 분홍 빛 펄스

**게임 오버**
- 블록을 놓을 곳이 없을 때
- 보드 흐려짐 + "다시 시작" 버튼 (살짝 슬픈 표정의 작은 캐릭터)

## ✨ 2) 머지 게임 (MergeGame)

### 컨셉
> "별먼지를 모아 더 큰 별로 키우는 마법 같은 시간"

### 화면 구성
```
┌────────────────────────────────────┐
│ [상단] 다음 별먼지 / 점수          │
├────────────────────────────────────┤
│                                    │
│    [6×6 또는 7×7 그리드]           │
│       ★ ☆ ☆                        │
│       ☆ ★ ★ ☆                      │
│       ☆ ☆ ★                        │
│                                    │
├────────────────────────────────────┤
│  [Lv.1 별먼지 추가] 버튼            │
└────────────────────────────────────┘
```

### 비주얼 요소

**배경**
- **밤하늘** 그라데이션 (분홍-보라-네이비)
- 별 입자가 천천히 흐름

**그리드**
- 6×6 또는 7×7 격자
- 격자: 거의 안 보이게 (반투명 별자리 라인)

**별먼지 레벨 시각**
| Lv | 모양 | 색 | 사이즈 |
|---|---|---|---|
| 1 | 작은 점 | 흰빛 | 24px |
| 2 | 작은 별 | 흰+분홍 | 32px |
| 3 | 별 + 빛살 | 분홍 | 40px |
| 4 | 별 + 빛살 강함 | 노랑 | 48px |
| 5 | 별꽃 | 살구 | 56px |
| 6 | 큰 별 | 라벤더 | 64px |
| 7 | 별+달 | 보라+은 | 72px |
| 8 | 별+오라 | 청록 | 80px |
| 9 | 큰 별구 | 무지개 | 88px |
| 10 | 거대한 별 | 황금+무지개 | 96px ⭐ |

**머지 연출**
- 두 별이 **빛으로 합쳐지며** 폭죽
- Lv.7+ 부터 **화면 흔들림** + 더 큰 폭발
- Lv.10 도달 시 **풀스크린 별가루 + 팡파레**

**그리드 가득 차면 게임 종료**
- 별먼지를 모두 합칠 수 없을 때
- 부드러운 다이얼로그 "오늘은 여기까지!" + 보상 표시

## ❓ 3) 퀴즈 (Quiz)

### 컨셉
> "주인님 박사가 되는 따뜻한 시간"

### 화면 구성
```
┌────────────────────────────────────┐
│  Q1 / 5     [● ○ ○ ○ ○]            │  ← 진행 인디케이터
├────────────────────────────────────┤
│                                    │
│  ┌──────────────────────────────┐ │
│  │ Q. 고양이가 골골거리는        │ │  ← 카드
│  │    이유는 무엇일까요?         │ │
│  │                              │ │
│  │  A. 행복할 때                │ │
│  │  B. 화날 때                  │ │
│  │  C. 둘 다                    │ │
│  │  D. 모름                     │ │
│  └──────────────────────────────┘ │
│                                    │
│  ⏱  10초                            │
└────────────────────────────────────┘
```

### 비주얼 요소

**배경**
- **북카페** 느낌 (책장이 흐릿하게 뒤에)
- 부드러운 따뜻한 빛

**카드**
- 명함 크기 (3:4 비율)
- 크림 화이트 + 분홍 테두리 (3px)
- 가벼운 그림자 (떠 있는 느낌)
- 모서리 살짝 둥글게 (radius: 12)

**카드 뒷면**
- 분홍 + 작은 발자국 패턴 (반복)
- 카드 뒤집기 애니메이션 (0.5초)

**선택지 버튼**
- 4개 박스 (큰 탭 영역)
- 기본: 흰 배경 + 분홍 테두리
- 호버/터치: 분홍 배경
- 정답: 민트 #B9FBC0 + ✓ (초록)
- 오답: 살구 #FFADAD + ✕ (살구)

**정답 연출**
- 카드 뒤집기 → 답 공개 → ✓ 표시
- 정답 시: 별가루 + 작은 박수 사운드
- 오답 시: 카드 살짝 좌우 흔들 + 아쉬움 사운드

**진행 인디케이터 (상단)**
- 5개 점 (현재 ● / 정답 ✓ / 오답 ✕ / 미완 ○)

**시간 제한 (하단)**
- 10초 카운트다운
- 5초 이하: 살짝 불안한 노란 강조
- 0초: 자동 다음 (오답 처리)

## 🎰 4) 가챠 화면 (보너스)

### 컨셉
> "마법 캡슐 자판기에서 새 친구를 만나는 순간"

### 화면 구성
```
┌────────────────────────────────────┐
│              [✕] 닫기              │
├────────────────────────────────────┤
│                                    │
│      ┌─────────────────┐           │
│      │   ★ 자판기 ★    │           │
│      │                 │           │
│      │  [캡슐 굴림]    │           │
│      │                 │           │
│      └─────────────────┘           │
│                                    │
│   [💎 마법돌 1개 = 1회]            │
│   [          뽑기          ]       │
│                                    │
│           [확률 보기]              │
└────────────────────────────────────┘
```

### 비주얼 요소

**자판기**
- 분홍 + 골드 액센트
- 위쪽 유리창 → 캡슐들 보임
- 하단 슬롯 → 캡슐이 굴러나옴

**캡슐**
- 일반: 흰 + 약한 빛
- 희귀: 파랑 + 중간 빛
- 전설: 무지개 + 강한 빛

**굴리는 연출 (1.5~2초)**
- 캡슐이 **굴러서 슬롯에 떨어짐**
- "쿵" 효과 + 살짝 흔들림
- 캡슐이 **빛나며 열림**
- 캐릭터 등장 (**확대 → 정상 사이즈** 페이드인)
- 등급에 따른 **오라 효과** (전설 = 무지개 빛)

**결과 화면**
- 캐릭터 정면 + 이름 + 등급 + tmi 1줄
- 하단에 "다시 뽑기" / "확인" 버튼

## 🎁 5) 보상 / 레벨업 / 출석 화면 (보너스)

### 출석 체크
- 캘린더 형태 (7일)
- 오늘 칸이 빛남 → 탭 → 보상 +
- 7일째: **마법돌 큰 보상** + 팡파레

### 레벨업
- 풀스크린 오버레이 → 레벨 숫자가 펑 등장
- 분홍 빛 + 별가루
- 보상 리스트 페이드인

### 데일리 미션
- 우측 사이드 패널 또는 별도 버튼
- 3개 미션 + 진행도 바

## 💡 작업 팁

- **연출 1초가 게임 인상의 80%**: 보드보다 **연출 일러스트** 에 시간 더 쓰기
- **별가루 / 빛 입자** 는 SVG / Phaser particle 로 코드 처리 가능. 일러스트는 **정적 보드**에 집중
- **카드 뒷면** 은 한 번 만들면 모든 퀴즈에 재사용 (300번 노출됨)
- **블록 색**은 색맹 사용자도 구분되게 명도 차이 두기
