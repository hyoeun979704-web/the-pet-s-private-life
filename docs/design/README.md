## 🎯 한 줄 요약

> **"집사가 자리를 비운 사이, 우리 집 주인님(반려동물)이 영역 본능으로 집을 가꾸는 따뜻한 힐링 시뮬레이션."**

- 장르: 캐주얼 인테리어 시뮬레이션 + 미니게임 + 가챠
- 플랫폼: Android (Google Play, 첫 출시 대만/홍콩 → 한국)
- 타겟: 20~40대 여성, 반려동물 호감 + 힐링 게임 선호
- 화면: 가로 풀스크린 (1920×1080 기준), 아이소메트릭 2D
