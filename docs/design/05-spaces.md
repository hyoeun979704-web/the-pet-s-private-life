## 🏠 전체 공간 컨셉

### 컨셉: "주인님의 비밀 아지트"
유저가 실제 사는 집이 아닌, **주인님(반려동물)이 가꾼 환상의 거실**. 살짝 비현실적인 색감 + 따뜻함. 인스타에 올릴 만한 무드.

### 시점: 아이소메트릭 2D
- 카메라 각도: 약 30° 기울어진 비스듬한 시점 (top-down 도, side-view 도 아님)
- 깊이감: 가구가 앞뒤로 자연스럽게 정렬
- → Phaser 의 PLACEMENT_CONFIG `isoAngleDeg: 30`

### 해상도
- 게임 베이스: **1920 × 1080 (가로)**
- 배경 이미지: 1920×1080 또는 좀 더 넓게 (스크롤 가능)

## 🛋️ 거실 (room_living) — 메인 화면

> **이 게임을 켜면 가장 먼저 보는 화면**. 가장 공들여야 하는 공간.

### 분위기
- **늦은 오후 햇살** 이 창문으로 들어오는 시간대
- 노란 백열등 조명이 켜진 따뜻한 방
- 부드러운 그림자, 진한 그림자 X
- 색온도: **따뜻한 톤** (3000K 느낌)

### 공간 요소
| 요소 | 위치 | 비고 |
|---|---|---|
| 창문 | 왼쪽 또는 뒤편 | 햇살 들어오는 방향 |
| 소파 / 매트 | 중앙 또는 오른쪽 | 주인님 idle 위치 |
| 러그 | 바닥 중앙 | 가구 배치 그리드 시작점 |
| 작은 탁자 | 소파 옆 | 컵·책 등 소품 위 |
| 화분 | 모서리 1~2개 | 몬스테라·다육이 |
| 벽 액자 | 벽 1~2개 | 캐릭터 그림자 또는 발자국 |
| 벽시계 | 벽 1개 | 살짝 5시 30분쯤 (퇴근 무드) |

### 공간 위계 (시선 흐름)
```
[1] 창문에서 들어오는 빛 (시선 시작)
       ↓ 시선이 따라감
[2] 러그 위 주인님 (메인 캐릭터)
       ↓
[3] 주변 가구 (배치 가능 슬롯)
       ↓
[4] 벽·코너 (디테일)
```

### 거실 사이즈
- 그리드: **약 8 × 5 타일** (타일 1개 = 64×64px)
- 벽까지 포함하면 1500×800 px 정도가 게임 카메라 영역
- 그 외 영역은 어두운 배경 또는 데코로 채움

### 색감
- **벽**: 크림 베이지 (#FAEDCB ~ #F3E8E2)
- **바닥**: 우드 톤 (옅은 갈색, 너무 어둡지 않게)
- **창 너머**: 연한 하늘 분홍빛 (저녁 노을)
- **러그/포인트**: 분홍 / 민트 / 연파랑 등

## 🛏️ 침실 (room_bedroom) — 레벨 5 해금

### 분위기
- **밤 시간대** (창에 별·달)
- 따뜻한 무드등 (작은 노란 등)
- 더 진한 분홍·라벤더 톤 (저녁 색감)

### 공간 요소
| 요소 | 위치 | 비고 |
|---|---|---|
| 침대 | 중앙 | 주인님 sleep 위치 |
| 협탁 | 침대 옆 | 알람시계·물컵 |
| 옷장 | 한쪽 벽 | 큰 가구 |
| 창문 (밤) | 벽 | 달·별 |
| 무드등 | 협탁 위 | 따뜻한 빛 |
| 러그 | 바닥 | 침대 발치 |
| 벽 액자 | 벽 1개 | 가족 사진 또는 별 그림 |

### 침실 vs 거실 차이
- 거실: **밝음, 활발, 낮**
- 침실: **어둑, 차분, 밤**
- → 같은 게임이지만 시간대 변화로 신선함

## 🎮 미니게임 화면 배경

### 공통 원칙
- 미니게임 진입 시 **거실 위에 반투명 배경** + 미니게임 보드
- 거실이 아래 살짝 보이게 (몰입감)
- 게임 보드 자체는 **별도 일러스트** 권장 (배경의 노이즈 X)

### 🧩 블록 퍼즐 배경
- **나무 트레이** (상단) — 주인님 간식이 떨어지는 그릇
- **격자 보드** (하단 중앙) — 8×8 또는 9×9
  - 격자 색: 옅은 베이지 / 분홍 alt
  - 그리드 라인: 거의 안 보일 정도로 약함
- **블록 색**: 5~7가지 색 (분홍/민트/노랑/살구/연파랑/연보라/베이지)
- 보드 주변 데코: 작은 쿠션·인형 1~2개

### ✨ 머지 게임 배경
- **별이 빛나는 밤하늘** 배경 (살짝 어둡게, 그러나 따뜻함 유지)
- 보드: **6×6 그리드** 가까운 사이즈
- 별먼지 아이콘: Lv.1 작은 별 → Lv.10 거대한 별
- 합쳐질 때 빛 폭발 효과

### ❓ 퀴즈 배경
- **북카페 같은 따뜻한 배경** (책장이 흐릿하게 뒤에)
- 퀴즈 카드: **명함 크기의 카드**가 화면 중앙에 등장
  - 카드 색: 크림 + 분홍 테두리
  - 카드 뒷면: 분홍 + 작은 발자국 패턴
- 정답 시: 카드 뒤집히며 ✓ + 별가루
- 오답 시: 카드 살짝 흔들리며 ✕ (빨강 X, 살구 #FFADAD 으로)

### 🎰 가챠 화면
- **마법 캡슐 자판기** 비주얼 (아케이드 캡슐 머신)
- 자판기 색: 분홍 + 골드 액센트
- 캡슐 색: 흰 → 파랑 → 무지개 (등급별)
- 배경: **부드러운 분홍 그라데이션** + 별 입자
- 결과 공개: 캡슐이 빛나며 열림 → 캐릭터 등장

## 🌅 시간대 변화 (선택 — Phase 2)

같은 거실의 다른 시간대:

| 시간 | 색온도 | 분위기 |
|---|---|---|
| 아침 (06~10) | 청록빛 차가움 | 새벽 햇살 |
| 낮 (10~16) | 화이트 톤 | 활기 |
| 저녁 (16~20) | 분홍 노을 ⭐ | **메인 톤** |
| 밤 (20~) | 보라+노랑 등불 | 침실 톤 |

> β 출시는 **저녁 톤 1개**로 충분. 시간대 변화는 정식 출시 후 옵션.

## 📐 가구 배치 그리드 (참고)

- 그리드: 64×64 px 한 칸
- 가구는 1×1, 1×2, 2×2 등 다양한 크기
- 모든 가구는 발치(아래쪽) 기준으로 정렬

```

└─────────────────────────┘
```
