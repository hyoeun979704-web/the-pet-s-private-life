## ⚠️ 7) 라이선스 체크리스트 (필수)

자산 받을 때마다 확인:

- [ ] **상업 이용 (Commercial Use)** OK 인가?
- [ ] **수정 (Modification)** OK 인가?
- [ ] **출처 표기 (Attribution)** 의무 있는가?
- [ ] **재배포 (Redistribution)** 제한 있는가?
- [ ] **AI 학습 / 게임 자산** 명시 제한 있는가?

### 흔한 라이선스 요약
| 라이선스 | 상업 | 수정 | 출처 |
|---|---|---|---|
| CC0 (Public Domain) | ✅ | ✅ | ❌ (의무 X) |
| CC-BY | ✅ | ✅ | ⭐ 의무 |
| CC-BY-SA | ✅ | ✅ | ⭐ + 같은 라이선스 |
| CC-BY-NC | ❌ 비상업만 | ✅ | ⭐ |
| MIT / Apache | ✅ | ✅ | ⭐ |
| Royalty-Free (구매) | ✅ | ✅ | ❌ (보통) |

> **출처 의무 라이선스** 사용 시 `src/assets/audio/LICENSES.md` 같은 파일에 모두 기록. Play 심사에서 직접 묻진 않지만 **분쟁 방지용 필수**.

## 💡 작업 팁

### "사기 전에 시범 작업"
- 외주 / 유료 자산 사기 전 **1개 무료 샘플로 검증**
- 게임에 실제로 넣어보고 톤 맞는지 확인 → 그 후 양산

### "구독은 짧게"
- Flaticon, Epidemic Sound 같은 구독제는 **1주~1개월만** 쓰고 필요한 거 다 다운
- 출시 후 매월 부담되면 정리

### "라이선스 파일은 받자마자"
- 다운로드 직후 `LICENSES.md` 에 출처·라이선스 기록
- 나중에 잊으면 분쟁 시 증빙 불가

### "Niji Journey 한 번 시도"
- 우리 게임 톤(파스텔, deformed) 과 매우 잘 맞음
- 첫 1달 $10 만 결제해도 캐릭터 17종 시안 다 뽑아볼 수 있음
- → [`docs/assets/01-style-guide.md`](./01-style-guide.md) 의 Niji 프롬프트 참고
