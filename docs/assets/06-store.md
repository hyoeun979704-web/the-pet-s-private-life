# 06. 스토어 자산 (Play Console 등록용)

> **목표**: Play Console 출시에 필수인 모든 시각·텍스트 자산 (앱 아이콘 / 스플래시 / 스크린샷 / 배너 / 설명문)
> **소요**: 2~3일
> **사전조건**: 캐릭터 일부 + 메인 화면 자산이 있어야 스크린샷이 의미 있음 (Phase 2 후 권장)

---

| 항목 | 크기 | 개수 | 필수 | 비고 |
|---|---|---|---|---|
| 앱 아이콘 (foreground) | 1024×1024 | 1 | ⭐ | adaptive icon용 |
| 스플래시 | 2732×2732 | 1 | ⭐ | Capacitor 자동 리사이즈 |

## 🎨 1) 앱 아이콘

### 스펙
| 항목 | 값 |
|---|---|
| 파일명 | `resources/icon.png` (Capacitor 권장 위치) |
| 크기 | 1024×1024 px |
| 포맷 | PNG, 알파 채널 |
| 안전 영역 | 중앙 660×660 (시스템이 마스킹할 수 있음) |

### 디자인 가이드
- **단순할수록 좋음**: 작은 사이즈에서도 식별되어야 함
- **메인 캐릭터 1마리 + 분홍 배경** 권장 (예: 먼치킨 얼굴 클로즈업)
- 텍스트 NO (Google 정책)
- 그라데이션·그림자는 미니멀하게

### Capacitor adaptive icon 자동 변환
```bash
npm i -D @capacitor/assets
```

`resources/` 폴더에 다음 두 파일 배치:
- `resources/icon-foreground.png` (1024×1024, 알파 채널, 캐릭터만)
- `resources/icon-background.png` (1024×1024, 단색 `#FFC8DD` 또는 그라데이션)

또는 단일 파일:
- `resources/icon.png` (1024×1024, 전체)

```bash
npx capacitor-assets generate --android
npx cap sync android
```

자동으로 `mdpi/hdpi/xhdpi/xxhdpi/xxxhdpi/round/adaptive` 모든 사이즈 생성.

## 🌅 2) 스플래시

### 스펙
| 항목 | 값 |
|---|---|
| 파일명 | `resources/splash.png` |
| 크기 | 2732×2732 px (정사각) |
| 포맷 | PNG, 알파 NO (배경색 채워야 함) |

### 디자인 가이드
- 중앙에 **로고 또는 메인 캐릭터** (시스템이 가로/세로 비율 따라 크롭)
- 배경: `Constants.DESIGN_TOKENS.color.bg` = `#FFF7F2` 와 일치
- 안전 영역: 중앙 1024×1024 안에 핵심 요소 배치

### 위 generate 명령으로 자동 처리
`resources/splash.png` 두면 `npx capacitor-assets generate --android` 가 자동 변환.

## 🎬 3) 피처 그래픽

### 스펙
| 항목 | 값 |
|---|---|
| 크기 | **1024×500** px (가로) |
| 포맷 | PNG 또는 JPG |
| 위치 | Play Console에 직접 업로드 |

### 디자인 가이드
- Play Store 검색 결과·앱 페이지 상단에 노출
- **타이틀 텍스트** OK (앱 아이콘과 달리 텍스트 허용)
- 캐릭터 2~3마리 + 게임 타이틀 + 짧은 캐치프레이즈

### 권장 레이아웃
```
[ 캐릭터 3마리 일러스트 ]    주인님의 사생활
                            우리 집 주인님의 비밀 일상
```

---

## 📱 4) 스크린샷

### 스펙
| 항목 | 값 |
|---|---|
| 크기 | 1080×1920 (세로) 또는 1920×1080 (가로) |
| 개수 | 최소 2장, **권장 8장** (가능한 많이) |
| 포맷 | PNG 또는 JPG |
| 우리 게임 | **가로** (Capacitor + Phaser FIT 모드) |

### 8장 스토리보드 권장
1. **메인 화면** — 캐릭터 3마리 돌아다니는 따뜻한 거실
2. **블록 퍼즐** — 보드 + 트레이 + 콤보 효과
3. **머지 게임** — Lv.7 합치는 순간의 캡처
4. **퀴즈** — 정답 공개 화면 (교육적 어필)
5. **가챠 결과** — 전설 캐릭터 등장 화면
6. **확률 공시** — 등급별 확률표 (법규 어필 + 신뢰)
7. **가구 배치** — 풍성한 거실 (콘텐츠 어필)
8. **도감/캐릭터** — 17종 갤러리 (수집 욕구)

### 캡처 방법
1. 게임을 안드로이드 폰에서 실행 (디버그 빌드 OK)
2. 폰 스크린샷 (Power + Volume Down)
3. 또는 Android Studio에서 에뮬레이터로 → 카메라 아이콘
4. PC로 옮긴 후 Photoshop으로:
   - 1920×1080 으로 크롭
   - 텍스트 오버레이 추가 ("D1 리텐션 35%!" 같은 마케팅 카피)

### 스크린샷에 텍스트 오버레이 (권장)
한국어 마케팅 카피 예시:
- "주인님이 자리를 비운 사이..."
- "17종 캐릭터를 수집하세요"
- "하루 10분 힐링 퍼즐"
- "친구도, 가족도 같이!"

## 🎥 5) 프로모션 비디오 (선택)

### 스펙
- **YouTube 동영상 URL** 만 Play Console에 입력
- 권장 길이: **15~30초**
- 첫 5초가 가장 중요 (스토어에서 자동 재생)

### 구성 예시
- 0~3초: 메인 캐릭터 등장 + 타이틀
- 3~10초: 미니게임 3종 빠른 컷
- 10~20초: 가챠 + 가구 배치
- 20~30초: 캐릭터 3마리 + 다운로드 CTA

DaVinci Resolve 무료, 또는 캡컷 무료. 30초 영상은 1~2시간 작업.

## 📝 6) 짧은 설명 (80자)

### 가이드라인
- 80자 이내 (한국어 기준)
- 핵심 어필 + 핵심 키워드
- 이모지 OK

### 예시
> 우리 집 주인님의 비밀 일상 🐾 아기자기 힐링 시뮬레이션 + 미니게임으로 캐릭터 17종 수집

> 반려동물과 함께하는 따뜻한 인테리어 게임. 매일 10분 힐링.

## 💡 팁

- **스토어 자산은 캐릭터 일러스트 5종 만든 후에 작업**: 그래야 메인/스크린샷에 의미 있는 콘텐츠가 들어감
- **Figma 템플릿**: "Mobile App Store Mockup" 검색하면 무료 템플릿 풍부
- **스크린샷 텍스트 한 줄**: 빨간 강조보다 메인 컬러 분홍이 톤 일관성에 좋음
- **다국가 출시 대비**: 영어 설명도 미리 준비 (Google 자동 번역은 어색함)
- **A/B 테스트**: Play Console에는 스토어 노출 A/B 테스트 기능. 출시 후 활용
