## 🎯 추천 작업 순서

### Phase 1: 파이프라인 검증 (1~3일) — **가장 먼저**
캐릭터 1종 + 가구 1개 + 아이콘 1개를 실제 게임에 넣어서 동작 확인. 여기서 막히면 양산해도 다 다시 해야 함.
- → [`08-pipeline.md`](./08-pipeline.md) 먼저 보기
- → 그다음 [`02-characters.md`](./02-characters.md)의 첫 1종만

### Phase 2: MVP 분량 (1~2주)
β 출시 가능한 최소량:
- 캐릭터 5종 idle
- 가구 5종 (이미 데이터 있는 것)
- 자원 아이콘 5개
- BGM 1곡 + SFX 3개

### Phase 3: 풀 콘텐츠 (수 주)
- 캐릭터 17종 × idle/sleep
- 가구 150
- 미니게임 UI 풀세트
- BGM 5 + SFX 11
- 스토어 자산
- 캐릭터 텍스트

## 💡 1인 작업 핵심

1. **타임박스**: 한 캐릭터에 2시간 이상 안 쓰기. 완벽주의는 17종을 영원히 못 끝내게 함
2. **일괄 작업**: 하루는 고양이만 5종, 다음 날은 강아지만 6종. 시기 섞지 않기
3. **버전 관리**: PNG/OGG도 git에 commit (개별 파일 < 60MB)
4. **백업**: `src/assets/` 매주 클라우드 1회 백업
5. **음악은 마지막**: BGM/SFX는 진짜 끝물에 며칠로 몰아서

## 📂 최종 파일 구조 (참고)

```
src/assets/
├── characters/
│   ├── char_cat_munchkin_idle.png
│   ├── char_cat_munchkin_sleep.png
│   └── ... (× 17 × 2~3)
├── furniture/
│   ├── furn_rug_basic.png
│   └── ... (× 150)
├── ui/
│   ├── icon_resource_snack.png
│   ├── bg_quiz_card.png
│   └── ... (약 25)
└── audio/
    ├── bgm_lobby.ogg
    ├── sfx_tap.ogg
    └── ... (16)
```

총 예상 파일 수: **약 250개**, 압축 후 총 용량 **80MB 이내** (ROADMAP 성능 예산).
