# 04. UI 아이콘 + 미니게임 자산

> **목표**: 자원 아이콘 5 + 미니게임 보드/배경 + 가챠 UI + 광고 + 레벨 등 약 25개
> **소요**: 2~3일
> **사전조건**: [01. 스타일 가이드](./01-style-guide.md)

> 아이콘은 **Figma + 무료 아이콘 라이브러리**로도 충분. 캐릭터/가구만큼 시간 들이지 않아도 OK.

- 모두 같은 **외곽선 굵기** (2~3px)
- 모두 **둥근 모서리**
- **그림자 없음** (작은 아이콘에 그림자는 노이즈)

### 빠른 생성: AI 사용
```

soft outline, no gradient, isolated on transparent background,
mobile game UI icon, 2D vector style
```

## 🛠 추천 도구

### Figma (강력 추천)
무료. 컴포넌트화 → 색상만 바꿔서 변형 쉬움. Export → PNG 1x/2x 동시.

### Lucide / Phosphor / Heroicons (무료 라이브러리)
- 자원 아이콘은 거의 다 이런 라이브러리에 있음
- "candy" / "star" / "ticket" / "gem" 검색
- 라이선스 MIT — 상업 이용 OK

### Photopea (무료 웹 Photoshop)
설치 없이 바로. PSD 호환.

### Niji Journey
일러스트 베이스 만들 때.

## 💡 팁

- **이모지 활용도 OK**: 현재 코드는 🍖⭐🔮 같은 이모지 직접 사용 중. UI 아이콘 만들기 전까지는 이모지 그대로 두고 캐릭터/가구 우선
- **다크모드 대비**: 출시 첫판은 라이트 모드만. 다크모드는 출시 후
- **벡터 → 래스터 export**: Figma의 SVG export 후 Photopea에서 PNG 변환하면 깔끔
- **8-bit 컬러 한정**: 모든 UI 자산은 8개 디자인 토큰 색상만 사용 (이미지 일관성)
